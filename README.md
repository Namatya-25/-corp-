# 架空コーポレートサイト「株式会社SKYINFO」

架空のIT企業「株式会社SKYINFO」のコーポレートサイトを、HTML / CSS / JavaScript でコーディングしたポートフォリオ作品です。
デザインカンプをもとに、PC・タブレット・スマートフォンに対応したレスポンシブなLP形式の1ページサイトとして制作しました。

## 工夫した点

### 1. `clamp()` による滑らかなレスポンシブ対応
フォントサイズや余白の多くを `clamp()` で指定し、ブレイクポイントごとに値を切り替えるのではなく、画面幅に応じて連続的に変化するようにしました。

```css
margin-bottom: clamp(65px, 6.76vw + 38.4px, 125px);
```

### 2. 画面幅に応じたスライダーの挙動の切り替え
実績セクションのSwiperは、画面幅によって設定を変えています。

- **SP / タブレット（〜1023px）**：1枚ずつ表示し、ループ・スワイプ・矢印ボタンで操作
- **PC（1024px〜）**：3枚を横並びで表示し、ループとスワイプを無効化してカード一覧として見せる

### 3. ハンバーガーメニュー
SPではハンバーガーボタンでメニューを開閉します。メニューが開いている間は `body` にクラスを付けて背景のスクロールを止め、操作しやすくしています。

### 4. 保守しやすいCSS設計
- テキスト色やアクセントカラーをCSSカスタムプロパティ（`:root`）にまとめ、配色を一か所で管理
- 共通の `.container` やセクションタイトル（英字＋日本語サブタイトル）をコンポーネントとして使い回し
- モバイルファーストで記述し、`min-width` のメディアクエリでPC向けのスタイルを追加

### 5. 画像の出し分け
メインビジュアルのキャッチコピーは `<picture>` と `<source media>` でPC用とSP用の画像を切り替え、どの画面サイズでも読みやすくしています。
